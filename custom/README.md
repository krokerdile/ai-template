# Custom Skills

This directory is for your personal agent skills and experiments.

## Purpose

Use this space to:
- Create and test your own prompts
- Customize existing skills for your workflow
- Experiment with new approaches
- Store project-specific skills
- Keep skills you're developing before sharing

## Organization

You can organize your custom skills however works best for you:

```
custom/
├── by-language/
│   ├── python/
│   ├── javascript/
│   └── rust/
├── by-project/
│   ├── project-a/
│   └── project-b/
├── experimental/
└── favorites/
```

## Getting Started

1. Copy a template from `/templates/`
2. Modify it for your specific needs
3. Test and iterate
4. Document what works well

## Sharing Your Skills

If you create a skill that works well:
1. Polish the documentation
2. Add clear examples
3. Consider contributing it to the main directories
4. Share with the community

## Tips for Custom Skills

- **Keep Notes**: Document what works and what doesn't
- **Version Control**: Track changes to see improvements
- **Test Thoroughly**: Try skills in different contexts
- **Be Specific**: Tailor skills to your exact use cases
- **Combine Skills**: Chain multiple skills together

## Example Custom Skills

- Domain-specific code generation (e.g., game dev, ML, web3)
- Company/team coding standards enforcement
- Project-specific refactoring patterns
- Personalized code review checklists
- Custom documentation formats

## Backup

Consider backing up your custom skills regularly since they represent your personal workflow optimizations.
